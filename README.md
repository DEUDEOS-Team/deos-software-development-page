# 🌐 DEOS Software Development Portal

Bu depo, **DEOS Otonom Araç Ekosistemi**'nin dağıtık yazılım mimarisini, Git alt modül ağacını, araç içi CAN-FD donanım topolojisini ve tüm alt modüllerin canlı GitHub commit geçmişini sunan resmi web portalıdır.

## 🚀 Canlı Portal
Web sitesine aşağıdaki bağlantıdan erişebilirsiniz:  
👉 **[https://deudeos-team.github.io/deos-software-development-page/](https://deudeos-team.github.io/deos-software-development-page/)**

## 🛠️ Mimari & Özellikler
* **Canlı GitHub API Entegrasyonu:** Her uygulama ve alt modülün en son commit'i GitHub REST API üzerinden dinamik olarak çekilir.
* **İnteraktif Topoloji Şeması:** Mermaid.js ile çizilmiş araç içi donanım ve yazılım katmanları.
* **Hover Popover Bilgi Kartları:** Düğümlerin üzerine gelindiğinde sorumlu geliştiriciyi, son commit hash'ini, commit mesajını ve depo bağlantısını gösteren kartlar.
* **Modern UI:** Koyu tema, cam efektli (glassmorphism) paneller ve responsive tasarım.
